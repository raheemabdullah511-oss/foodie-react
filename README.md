# Foodie — Premium React Food Delivery Frontend

## Run
```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Included
- React + React Router
- Context API cart
- Demo auth with localStorage
- Search and category filters
- Restaurant sorting
- Dynamic restaurant menus
- Add/remove/update cart
- Checkout + fake order ID
- Responsive premium UI
- Local JS data
- No backend/API/payment processing

Food images use normal remote image URLs (not an API).
